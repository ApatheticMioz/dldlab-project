# Contributing to DLD Circuit Simulation

Thank you for your interest in contributing to this project!

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion:
1. Check if the issue already exists in the Issues tab.
2. If not, create a new issue with a clear description.

### Submitting Changes

1. **Fork** this repository.
2. **Clone** your fork locally.
3. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test them in Proteus.
5. **Commit** your changes with a clear message:
   ```bash
   git commit -m "Add: brief description of changes"
   ```
6. **Push** to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request** against the `main` branch.

### Pull Request Guidelines

- Keep changes focused and minimal.
- Include a clear description of what your PR does.
- Reference any related issues.
- Ensure Proteus project files are valid and can be opened.

### Code of Conduct

- Be respectful and constructive in all interactions.
- Help maintain a welcoming community for all contributors.

## Questions?

Open an issue if you have any questions about contributing.
